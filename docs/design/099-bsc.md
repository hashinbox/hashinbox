# 099: BNB Smart Chain

BSC is an EVM chain: same JSON-RPC, addresses, keys, EIP-1559 type 2
transactions (BEP-226) and `Transfer` logs (BEP-20 = ERC-20). So it is not a
new implementation.

## Decisions

- **Own crate, reused machinery.** `sdk/chains/bnb` (`chain-bnb`) depends on
  `chain-ethereum` and adds only BSC's identity and defaults: blocks, legs,
  balances, confirmation, fees, signing and broadcast are `chain-ethereum`'s.
- **Chain name `bnb`.** Ids read `bnb.mainnet.0x…`, `bnb.testnet.0x…`.
  Networks: `mainnet` (chain id 56), `testnet` (chain id 97). `Info` is
  `chain-ethereum`'s (`eth_chainId` is checked against the stored id).
- **`chain-ethereum` takes its family as configuration.** New
  `chain_ethereum::Family { chain, name, ticker }`; `ETHEREUM` is the default.
  `Network` carries its family (`Network::of`; `Network::new` stays
  Ethereum); `Config` carries it too (`Config::stored(config, family)`;
  `TryFrom` stays Ethereum). The native asset's name and ticker and the
  `base::Network` chain come from it. Ethereum's behaviour is unchanged.
- **`chain_bnb::Factory`** wraps `chain_ethereum::Factory` with
  `CHAIN = bnb` and builds a stored network through `chain_bnb::config`:
  BSC defaults under the stored `settings` (`interval_ms` 3000,
  `bump_after` 400 blocks, about 3 min at 0.45 s blocks).
- **Finality.** 0.45 s blocks (measured, both networks); fast finality
  finalizes within a few blocks. 15 confirmations (about 7 s), stored in the
  `network` row like every chain's.
- **Fees.** Unchanged code: BSC answers a zero `baseFeePerGas` and a
  0.05 gwei `eth_maxPriorityFeePerGas`, so max fee = 2·0 + tip = 0.05 gwei
  (checked against mainnet and testnet). Ethereum's ceilings fit.
- **Markets.** `BNB` is quoted by Binance (`BNBUSDT`), Kraken (`BNBUSD`),
  CoinGecko (`binancecoin`), and by Coinbase and Bitstamp by ticker (both
  list it). USDT/USDC already are.

## Nodes

Free, keyless: `https://bsc-rpc.publicnode.com` (mainnet),
`https://bsc-testnet-rpc.publicnode.com` (testnet); both serve batches,
`eth_getBlockReceipts` and `eth_getLogs`. Explorers: bscscan.com,
testnet.bscscan.com. Migration: `099-migrate-1.sql`.

## Not supported

- Legacy (type 0) transactions: sends are EIP-1559 type 2, as on Ethereum.
- BEP-2 / Beacon Chain assets, opBNB, Greenfield.
- Native BNB moved by contracts internally (as on Ethereum: no standard RPC
  records it).
- Errors still read "Ethereum …" (the shared code's messages).
- No mock BSC for the server's case suite: BSC is tested in `chain-bnb`
  over scripted nodes; the server cases run Ethereum's mock, the same code.
