# Currency symbols

`svg/black/*.svg` of [cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons)
0.18.1 (CC0-1.0), copied unchanged. One file per ticker, in lowercase; the
server serves them at `/assets/currencies/<ticker>.svg`. To add a currency,
copy its file from the same package and list it in `apps/server/src/ui.rs`.
